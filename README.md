# Actix

Пример приложения Actix, которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `7001` |
| Путь проверки состояния | `/` |

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
cargo fetch

# запуск в дев режиме
cargo run

# сборка для продакшн
cargo run --release
```
